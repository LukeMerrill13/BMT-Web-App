# Brian Mercer Trust (BMT) Web Application

This repository contains the code for the Brian Mercer Trust Web Application, a lightweight Python-based tool designed to process, analyse, and present the Trust’s grant-making data. The application cleans raw grant records, calculates annual spending, and prepares datasets for visualisation and reporting. It has been created for the trustees to faciltate improved and more efficient decision-making.


## BMT and data

The Brian Mercer Trust is committed to transparency, following grant-making best practices, and contributing to an open data ecosystem.
As part of this commitment, the Trust publishes its grant data in accordance with open data standards.
All data used in this application is extracted from 360Giving, the UK standard for open grant data.
The Trust manually updates these datasets whenever new grants are awarded to ensure the information remains accurate and up to date.
